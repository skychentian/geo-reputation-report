# 分层映射

默认两份，用于报告里的「本期三品牌对比」和两张趋势图：

- `品牌整体`：企业背景、品牌资产、合规、舆情、渠道、售后、竞争格局、社会责任等。
- `食用油`：产品、烹饪场景、健康/营养、成分、工艺、转基因、食用安全、口感、复购等。

映射在 `config/layer-map.json`，结构：

```json
{"version": 1, "layers": {"品牌整体": ["企业背景", "..."], "食用油": ["日常烹饪", "..."]}}
```

## 调整方法

1. 先跑 `extract_answers.py`，看输出里的 `unmappedTopics` 和每层题数/回答数。
2. 把遗漏主题加到对应层；不要把一个主题同时放进两层。
3. 重新提取，确认 `unmappedTopics` 为空。
4. 重新生成报告。分层变了以后，历史快照的 `series` 仍是按层存的；如果旧期分层与本期不一致，应先决定是否重跑旧期，不能直接拼接两套口径。

## 什么时候不要硬分两层

- 数据包只有产品题、没有品牌题：把 `layers` 改成一层（例如 `["全部问题"]`），报告会自动只展示一个对比组和一张趋势图；不要为了凑两张图把产品题硬拆成“品牌”。
- 竞品在某一层几乎没有提及：保留该层给目标品牌，但对比行显示「样本不足」，趋势图隐藏该竞品。
- 客户明确只要“品牌整体”或只要“食用油”：只保留一层，不要多造。

## 命名

层名会直接出现在报告的对比组标题、KPI 标签和趋势图标题。用客户能直接理解的词（如“品牌整体”“食用油”“产品与选购”），不要用内部 topic 名。
