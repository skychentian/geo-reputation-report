# 最终态度判定规则

判定对象是「这条回答最后让读者相信什么」，不是它提到了什么。品牌名出现、争议出现、竞品出现，都不自动等于正负。

## 四种标签

| 标签 | 判定标准 | 典型结尾 |
|---|---|---|
| 正向 | 最终明确认可品牌/产品可靠、口碑好、值得买、可长期用、可信任 | “可以放心买”“推荐”“值得长期回购” |
| 中性 | 正负并列、条件性判断、只梳理事实/参数/差异，没有清晰推荐或拒绝 | “看需求选”“各有优劣”“取决于配料表” |
| 负向 | 最终明确降低信任、影响购买、拒绝选择，或建议转向其他品牌 | “不建议买”“风险太大”“选别家更稳” |
| 无法判断 | 回答缺失、明显跑题、只有检索过程/引用列表，无法识别最终态度 | 空回答、只列链接 |

## 关键边界

1. **澄清争议 ≠ 负向**：回答说“某争议事件是谣言/官方未认定品牌 A污染”，但没有给出购买建议时，按中性；如果结尾明确说“所以可以放心买”，按正向。
2. **提到缺点 ≠ 负向**：回答说“品牌 A花生油香味不如品牌 C，但综合性价比高，推荐日常用”，目标品牌按正向；品牌 C在该维度被认可，品牌 C按正向或中性，取决于是否明确推荐。
3. **客观对比 ≠ 中立**：回答如果最后给出“日常家用选品牌 A、浓香选品牌 C”，两个品牌都按正向；如果只列参数不给结论，按中性。
4. **多品牌同时认可**：回答说“三家都符合国标，按需求选”，三个品牌都按正向；如果只说“都能买，但我更推荐 A”，A 正向，其余中性或负向，按是否被否定。
5. **竞品只在提及时输出**：回答没有提到品牌 C，就不要给品牌 C标签；不要用“没提=中性/0 分”补样本。
6. **不按主题判**：一条回答属于“食品安全/合规风险”主题，不代表它一定是负向；看最终结论。
7. **不按语气判**：回答语气激烈但结论是“谣言，可以买”，按正向/中性；语气温和但结论是“不建议”，按负向。
8. **不跨回答平均**：每条回答独立判定；同一问题在不同平台可能结论不同，分别保留。

## 竞品判定

- 回答明确比较 A/B 时，分别给 A、B 标签。
- 回答说“A 更好”，A 正向，B 负向或中性：如果明确否定 B（“B 不行/不建议”），B 负向；如果只是“B 也不错但 A 更适合”，B 正向或中性。
- 回答只提竞品名字但不评价（“品牌 A和品牌 C都是品牌”），竞品按中性或无法判断；没有态度就不算正向。
- 回答说“品牌 C花生油更香”属于对品牌 C的正向认可，但不等于对品牌 A的负向；品牌 A看它自己的最终结论。

## 输出

```json
{
  "id": "2026-10-15-1",
  "target": {"sentiment": "正向", "reason": "不超过40字", "evidence": "不超过40字原文"},
  "competitors": {
    "品牌 C": {"sentiment": "正向", "reason": "...", "evidence": "..."}
  }
}
```

- `reason` 写判断依据，不写“AI 认为”。
- `evidence` 摘原文短句，便于复核；不要改写原文。
- 每条回答必须有一条 label；`competitors` 没有就写 `{}`。
- 只输出 JSON，不要 Markdown 代码块、不要解释。

## 复核抽样

生成后至少抽 10 条（覆盖正向/中性/负向/竞品）人工复核。若发现系统性偏差（例如把所有“澄清谣言”都判成中性），先改规则再重跑，不要逐条打补丁。
